### 5. 描述 / 介绍 (Description) — 限 4000 字符
```text
BudNote 是一款专为 macOS 打造的轻巧、清新的原生纯文本与 Markdown 编辑器。完全采用 Swift、AppKit 与系统 WebKit 构建，无任何第三方库依赖，不打包臃肿的浏览器内核或额外运行时，启动迅速，内存占用极低。

【核心特性】

• 纯正 macOS 原生体验
遵循 macOS 人机界面指南，单行紧凑标题栏融合多文件标签页。标签支持触控板与鼠标滚轮横向滑动、快捷键切换（⌃Tab / ⇧⌃Tab）、关闭与未保存状态提示，切换标签丝滑不闪烁，全屏空间下不跳动。

• Markdown 三模式与实时同步预览
支持“编辑（⌘1）”、“双栏实时预览（⌘2）”与“阅读（⌘3）”三种模式一键切换。右侧预览画面按源码行位置精准跟随左侧编辑区平滑滚动，支持标题、段落、强调、删除线、列表、任务清单、引用、代码围栏、表格与超链接。

• 轻量代码语法高亮
支持 txt、md、markdown、swift、py、java、js、ts、html、css、json、xml、yaml、toml、ini、conf、sh、c、cpp、log 等 20 余种常见文本与代码文件。自动对关键词、字符串、注释与数字进行清晰着色；高亮仅作用于视图显示层，绝不污染原文件或干扰撤销栈。

• 多字符编码与换行符无损保存
原生支持 UTF-8、UTF-8 BOM、UTF-16 LE/BE、UTF-32 LE/BE 以及中文 GB18030（兼容 GBK / GB2312）编码。打开并保存时严格保留原文件编码、BOM 标记以及 LF / CRLF / CR 换行符；无法用原编码无损表示时主动提示，并提供“另存为编码选择”与一键“转换为 UTF-8”。

• 清雅护眼配色与自由排版
内置清新的“草木浅色”与“深林深色”主题，支持跟随系统、浅色、深色三种外观模式。支持 10–40 pt 等宽字体调整（可使用 ⌘+ / ⌘- 或按住 ⌘ 配合鼠标滚轮无级缩放），支持自动换行（⌥⌘W）与自适应宽度行号栏（⌥⌘L）。

• 完善的文档生命周期与快捷操作
依托 macOS NSDocument 架构，支持自动保存、系统版本历史恢复、重命名（文件 → 重命名…）、移动文件位置（文件 → 移到…）、区分大小写的增量查找与替换（支持全部替换与单步撤销），并在底部状态栏实时展示行列位置、字符总数、当前编码与换行格式。

• 中英双语与隐私安全
内置简体中文与 English 界面实时切换。严格运行于 macOS 应用沙盒（App Sandbox）内，100% 本地离线处理，无账号体系、无统计埋点、无网络追踪，完全守护您的文档隐私。

联系与反馈：wizzer@qq.com
```

### 5. Description (介绍) — Max 4000 Characters
```text
BudNote is a fast, lightweight, and serene native plain text and Markdown editor crafted exclusively for macOS. Built purely with Swift, AppKit, and system WebKit—with zero third-party dependencies and no bundled browser runtimes—it launches instantly and keeps memory usage minimal.

KEY FEATURES

• Pure Native macOS Experience
Designed around a unified compact titlebar with single-row document tabs. Scroll horizontally through open tabs with your trackpad or mouse wheel, switch tabs via keyboard shortcuts (⌃Tab / ⇧⌃Tab), and work seamlessly in macOS fullscreen spaces without window flicker.

• Three Markdown Modes & Scroll-Synced Preview
Switch effortlessly between Edit (⌘1), Split Live Preview (⌘2), and Read (⌘3) modes. In Split Preview, the rendered preview pane tracks your exact source line position smoothly as you scroll. Supports headings, emphasis, strikethrough, lists, task checklists, blockquotes, fenced code blocks, tables, and links.

• Clean Lexical Syntax Highlighting
Supports over 20 plain text, configuration, and source code formats including txt, md, markdown, swift, py, java, js, ts, html, css, json, xml, yaml, toml, ini, conf, sh, c, cpp, and log. Highlights keywords, strings, comments, and numbers cleanly without altering file bytes or undo history.

• Lossless Character Encodings & Line Endings
Reads and writes UTF-8, UTF-8 with BOM, UTF-16 LE/BE, UTF-32 LE/BE, and Chinese GB18030 (GBK/GB2312). Faithfully preserves original file encodings, BOM headers, and LF / CRLF / CR line endings on save, with a custom Save As encoding picker and one-click Convert to UTF-8 command.

• Adaptive Meadow Themes & Typography
Includes soothing Meadow Light and Meadow Dark color palettes that can follow your macOS system appearance or be locked to Light or Dark mode. Customize monospaced font size from 10 pt to 40 pt (via ⌘+ / ⌘- or Command + Mouse Wheel zoom), toggle word wrap (⌥⌘W), and display adaptive line numbers (⌥⌘L).

• Complete Document Workflow
Powered by NSDocument with native autosave, version history revert, in-place file Rename, Move To folder, and case-sensitive incremental Find & Replace with full undo/redo support. A clean bottom status bar displays real-time line/column coordinates, character count, encoding, and line ending format.

• Bilingual UI & Privacy First
Switch instantly between Simplified Chinese and English inside Settings. Runs strictly inside the macOS App Sandbox with 100% local offline processing—zero analytics, zero telemetry, and zero cloud tracking.

Support & Feedback: wizzer@qq.com
```
