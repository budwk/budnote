BudNote 隐私政策

生效日期：2026 年 10 月 16 日

感谢您使用 BudNote（Bundle ID：com.budwk.app.budnote）。BudNote 是一款运行在 macOS 上的本地原生纯文本与 Markdown 编辑器。我们高度重视您的隐私保护。

1. 零数据收集承诺

BudNote 不会收集、上传、存储或分享您的任何个人身份信息、设备信息、使用统计数据、崩溃日志或文档内容。应用内无任何第三方统计或广告 SDK。

2. 本地文件与沙盒安全

BudNote 严格在 macOS App Sandbox（应用沙盒）内运行，仅访问您通过“打开”、“保存”、“另存为”、“移到”或拖拽操作主动授权的本地文件。您的所有文稿均保存在您自己的设备本地。

3. 网络权限说明

文本编辑、代码高亮与 Markdown 渲染完全离线完成。仅当您主动点击文档内的外部链接（http / https / mailto）或“关于”窗口中的项目主页时，系统才会调用默认浏览器打开。

4. 联系我们

如有任何关于隐私政策的疑问，请联系：wizzer@qq.com。

BudNote Privacy Policy

Effective Date: October 16, 2026

Thank you for choosing BudNote (Bundle ID: com.budwk.app.budnote). BudNote is a native macOS plain text and Markdown editor designed with privacy at its core.

1. Zero Data Collection

BudNote does not collect, transmit, store, or share any personal information, device identifiers, analytics, telemetry, or document content. No third-party tracking or advertising SDKs are included.

2. Local File Access & App Sandbox

BudNote runs strictly within the macOS App Sandbox and only accesses local files that you explicitly open or save via macOS file panels or Finder actions. All documents remain on your Mac.

3. Network Usage

All editing, syntax highlighting, and Markdown rendering happen 100% offline. External links are only opened in your system browser when you explicitly click on them.

4. Contact Us

If you have any questions regarding this Privacy Policy, please contact us at wizzer@qq.com.
